# Лендинг ДОСААФ

Статичный лендинг на HTML, CSS и JavaScript без конструкторов и внешних ассетов.

## Локальный запуск

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173`.

## Проверка

```bash
npm install
npm run test:site
npm run test:visual
```

Визуальные снимки создаются в `test-results/` и не попадают в Git.
